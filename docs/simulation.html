What this does not know

It knows scores, not injuries: a starting quarterback lost next week changes a team's chances and this page will not see it until the results show it. Conference tiebreakers are simplified to a coin flip after conference wins, so a two-way tie's odds are slightly off. And the committee is modelled from what it has valued in past years — résumé far more than strength — not asked.

Deterministic for a given set of results and ratings: the same inputs give the same page, so it changes when something happened and not otherwise.
